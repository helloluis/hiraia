# Gemini image queue — Hiraia illustration library

We are building a **retrieval** library of educational illustrations for the Hiraia
tutor: the tutor's text answer is matched against a captioned index, and the best
matching picture is shown alongside it. Because it's retrieval (not generation at
runtime), the pictures can be **pre-made raster PNGs** — which look far better for
recognizable subjects than the hand-authored SVGs we tried earlier.

## Division of labor
- **Gemini makes the images.** It reads the prompt files in `prompts/` and renders
  one PNG per entry. That's all Gemini does.
- **We make the captions + the index.** Every image is keyed by an `id`; its caption
  and metadata live in `../assets/<subject>/<id>.json` (multilingual `caption`/`parts`
  in English, Tagalog, Bisaya). Gemini does not touch these.

## The house style (every prompt already embeds it)
Black-and-white hand-drawn line art, like a clever child sketched it with a thick
black marker: one bold heavy black outline, dark areas as loose black scribble
shading, otherwise **no color**, on a **flat plain white background**; simple and
uncluttered but **proportionately correct**; **no text/letters/labels** in the image
(we overlay labels separately, per language); subject centered with white margins;
square. Reference: `../samples/cow.jpeg`.

## Folder structure
```
packages/images/
  gemini-queue/
    README.md            ← this file
    build-prompts.mjs    ← regenerates prompts/ from our inventory
    append-expansion.mjs ← appends the 2500-expansion concepts to the bottom of prompts/
    prompts/
      animals.json            plants.json
      human-body-health.json  cells-life-processes.json
      ecosystems-environment.json
      matter-chemistry.json   forces-energy-physics.json
      earth-weather-space.json
      daily-life-scenes.json  tools-figures-misc.json
      filipino-food.json      filipino-culture.json   ← new (2500-expansion)
  assets-png/            ← Gemini WRITES the images here (create as needed)
    biology/<id>.png   chemistry/<id>.png   physics/<id>.png
    earth-science/<id>.png   general/<id>.png
  assets/                ← existing SVGs + the caption/metadata records (keyed by id)
```
Each topic is its own file so images can be produced incrementally — start on
`animals.json` without waiting for the rest to be written.

## Naming convention
- `id` is the single key (kebab-case, unique) shared by the prompt, the PNG, and the
  caption record.
- Output image MUST be saved to the entry's `output_png` path, i.e.
  **`assets-png/<subject>/<id>.png`**.
- Caption/metadata for the same picture is `assets/<subject>/<id>.json`.

## Prompt file format
```jsonc
{
  "topic": "animals",
  "style": "…the shared style string…",
  "count": 44,
  "images": [
    {
      "id": "carabao-kalabaw",
      "name": "Carabao (Kalabaw)",
      "subject": "biology",
      "topic": "animals",
      "output_png": "assets-png/biology/carabao-kalabaw.png",
      "status": "todo",          // flip to "done" after rendering
      "prompt": "Full illustration of carabao … <full style baked in>"
    }
  ]
}
```
Render each `prompt` to a ~512×512 PNG at the `output_png` path; flip `status` to
`done`. Palette/indexed PNG keeps these tiny (a few KB each at minimal colors).

## Daily factoid feature (why we need thousands)
Hiraia sends the student a **morning (7:00) and evening (20:00)** chat message: a
random image from this library + a short factoid about it. With two sends a day and
no repeats, a wide, recognizable, factoid-worthy library matters — hence the bias
toward concrete single subjects (an animal, a fruit, a dish, a festival) over abstract
diagrams. The **factoid text is NOT part of this image queue** — it lives with the
caption metadata in `assets/<subject>/<id>.json` (authored separately, like captions),
where each record will carry trilingual `factoid` lines (en/tl/ceb). Gemini's only job
here is still: render the `prompt` → `output_png`, flip `status` to `done`.

## Notes / open items
- **Captions:** the ~420 original assets already have multilingual captions; the
  ~658 newly-planned concepts still need captions (our task, separate from Gemini).
- **Diagrams need a correctness check.** Schematic prompts (circuits, water cycle,
  body systems, Punnett squares…) include the required elements in the prompt, but a
  generative model can still get structure wrong — QC these against the curriculum.
- **Label-free is deliberate** — the tutor overlays labels in the student's language
  (English/Tagalog/Bisaya) on top of the card, so the image must contain no text.
