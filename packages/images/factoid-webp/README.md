# Factoid feed illustrations (WebP)

**18,816 grayscale WebP images**, one per prompt-bearing factoid in `rag/bank/factoids.jsonl`.
Filename = the factoid id (`ffct-NNNNN.webp`), so the file name *is* the factoid→image mapping.

- **Style:** black-and-white pen-and-ink "vintage scientific encyclopedia engraving" (one-shot, no post-processing).
- **Format:** grayscale WebP, 512×512, quality 80 (~32 KB avg, ~607 MB total). This is the **shippable master**.
- **Generated by:** `packages/images/qwen-queue/` pipeline — mostly OpenAI `gpt-image-2` (low) via the Batch API, with `qwen-image` filling the ~43 that OpenAI's safety filter declined (biology/body topics). Processed to WebP by `process-images.py`.

## ⚠️ Original full-res PNGs are NOT in this repo
The raw 1024×1024 RGB PNGs (~18 GB) are **stored in Dropbox → `Projects/hiraia`**, not committed
(too large). These grayscale WebPs are derived from them. If you ever need to **re-process at a
different size/quality**, pull the originals from Dropbox — regenerating from scratch costs ~$56 + a day.

## Regenerating (if ever needed)
Prompts live in `rag/bank/factoids.jsonl` (`image.prompt`). The full pipeline
(worklist → batch/sync generate → download → process) is in `packages/images/qwen-queue/`; the
OpenAI batch-download gotcha (API 504s on large outputs; use the platform's signed blob URLs via
`download-signed.sh`) is documented there.
