EXPENSIVE / RISKY TO PORT

  • Sepia multiply wash — the one real cost. An overlay View with mixBlendMode:'multiply' needs RN 0.76+ on the New Architecture. Toggle it off above: the design still holds, the plate just becomes pure white. Skia is the fallback if blend modes are unavailable.
  • Paper speckle — two tiled radial-gradients here. In RN ship a 24×24px tiled PNG (<1KB) as an ImageBackground, or drop it entirely.
  • aspect-ratio + max-height on the mount — RN supports aspectRatio, but combining it with maxHeight:'100%' inside a flexing parent is the one layout thing to test on-device; the safe port is measuring the mount slot with onLayout and sizing the square from the smaller edge.

FREE / DIRECT PORT

  • Every rule, frame, tick mark, cartouche, pip and fleuron is a plain View with borderWidth / borderRadius / rotate(45deg) — no pseudo-elements, no SVG, no CSS grid anywhere in the card.
  • Type ramp is three Google families; all three ship as static TTFs. Fraunces is variable here — bundle the static Regular / SemiBold / Bold + Italic instead (~4 files) and drop font-variation-settings.
  • The fork's stacked "ghost" sheets are two absolutely-positioned Views with a rotate transform behind the card. Cheap.
  • Contrast: ink #2A2620 on stock #EDE3CC = 11.8:1; muted #605847 on stock = 5.5:1; chalk on clay = 5.3:1; chalk on forest = 7.7:1. All AA or better for daylight on a cheap panel.
