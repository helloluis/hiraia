Risograph Print Shop

Every card is a page torn out of a zine a cool teacher ran off on the school riso: warm newsprint stock, three low-saturation inks that overprint and mis-register by a few pixels, halftone grain — and the greyscale plate duotoned in federal blue with a coral ghost, so the artwork stops looking like clip-art and starts looking printed.

REACT NATIVE — WHAT COSTS SOMETHING

  • HARDThe duotone plate is two stacked blend passes. Each illustration is drawn twice: a coral copy offset 4.5×3px and a blue copy on top, each lighten-blended against an ink-coloured box, and the whole box multiply-blended onto the pale plate. That knocks the white background out and recolours the line art in one move. RN 0.76+ ships mixBlendMode + isolation, so this works natively — but it is 2 extra image decodes per card and blend layers are the slowest thing on an Adreno 610. Cheaper escape hatch: bake the blue duotone into all 23,044 WebPs offline (one pipeline run, zero device cost) and keep only the coral ghost as a live blend — or drop the ghost entirely on low-end devices. The design still reads without it.
  • MIDPaper grain + halftone screen are CSS-generated. The grain is an inline SVG feTurbulence; the halftone is a repeating radial-gradient. Neither exists in RN. Both become a single tiled PNG in an <ImageBackground> with resizeMode="repeat" — trivial, but someone has to export the tiles. Pure polish: the direction survives without them.
  • MIDFull-bleed bands inside a padded sheet (the green SANGANDAAN banner, the mustard quiz header) use negative horizontal margins. RN supports negative margins, but it is cleaner to restructure so the sheet has no horizontal padding and every non-bleeding row carries its own.
  • FINEEverything else ports 1:1. Every hard offset shadow (4px 4px 0, no blur) is RN 0.76+'s boxShadow string prop; on older RN, Android's elevation cannot do a zero-blur offset, so fall back to a duplicated absolutely-positioned View — identical result, one extra node. The rotations (±0.4–1.3°) are transform: rotate. The mis-registered double rule, crop marks and the hand-inked Y are plain Views with borders — no SVG, no pseudo-elements carrying structure. Dashed borders on Android RN render slightly differently than iOS; if that bites, swap the perforation for a row of small Views.
  • FINEFonts. Three families, but only 3 static cuts are actually needed (Fraunces 600 + 700 can be shipped as static instances of the variable font, Bricolage 450/700, Courier Prime 400/700). The Fraunces WONK/SOFT axes are baked at export time, not animated — so no variable-font runtime is required on device.
  • FINEContrast, measured. All body copy is #1A1C22 on newsprint = 14.5:1. Black on coral = 5.8:1, black on mustard = 7.0:1, newsprint on green = 5.4:1, newsprint on blue = 8.7:1. Coral is deliberately never used as text on stock (2.5:1 — it fails), only as fill, rule and mis-registration ink.
