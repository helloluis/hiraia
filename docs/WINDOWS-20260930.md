# Windows preview — 30 September 2026

Scope: Windows 10/11 on Intel/AMD x64, the shared wide-screen Hiraia reader, and an
automatic Android + ChromeOS + Windows build. The Windows ZIP is an unlisted preview;
this work does not replace the public v0.4.27 APKs or add a public website download.

## Implementation

- Electron 44.5.0 hosts the existing Expo/React Native reader through React Native Web.
  The renderer is sandboxed, has no Node access, uses an application-only script CSP,
  and accesses app-owned files and native inference through bounded IPC.
- QVAC SDK 0.17.1 runs real local LaBSE embedding and Hiraia-2B generation. Windows uses
  CPU inference. A pinned Vulkan 1.4 loader and the official Microsoft C++ runtime ship
  with the app, including dependency provenance and notices.
- Cards, curriculum, quizzes, profile persistence and English/Tagalog ONNX voices ship
  in the application. Optional model downloads retain the shared memory gates and
  resume semantics. Device paths use native file URLs, including spaces and Unicode.
- The shared adaptive reader retains the compact toolbar and 3.5-card layout where it
  fits, narrows as the window/text grows, and keeps quiz content scrollable. Keyboard,
  pointer/trackpad, inactive-card focus isolation, reduced motion, high contrast and
  system screen-reader layout have desktop implementations.
- Preview limitation: Tala Nearby is Android-only. Windows exposes no false enrolment
  flow and never offers an Android APK update. Windows previews are replaced manually;
  profiles and downloaded content remain in the user's Hiraia AppData directory.

## Validation evidence

The native Windows control first passed in
[run 36660467556](https://github.com/helloluis/hiraia/actions/runs/36660467556).
The first complete extracted Windows package passed in
[run 36663059653](https://github.com/helloluis/hiraia/actions/runs/36663059653), commit
`88c4b76983f1461af98bb8baab30284f25dd3543`. That run verified offline first use,
keyboard input, quiz answers at 200% zoom and 900×600, profile/quiz persistence,
768 finite embedding values, CPU generation of the correct Sun control answer,
and non-silent English and Tagalog voice synthesis. The ZIP was extracted under a
path containing both spaces and Unicode before execution.

Subsequent testing found that React Native Web moves the rail without emitting
Android's drag/momentum events. Commit `7a248684e` connects browser gestures to the
active-card state; the end-to-end test now requires trackpad movement to advance it.
Commit `1c486a0d8` adds real Listen-button playback and updates the Android test loader
to include the new native no-op hook. Its 26 reader/review tests pass locally.
The local formal model gate passed all 45 cases with five draws per stochastic case
(185 card draws); no gate, model prompt or scientific content was weakened.

The CI host is Windows Server 2022 x64. Windows 10/11 compatibility is the supported
target according to [QVAC's requirements](https://docs.qvac.tether.io/system-requirements/),
not a claim that physical Windows 10 and Windows 11 devices were tested here. Manual
NVDA/Narrator and consumer-device acceptance remain necessary before a general release.
The preview has no Authenticode certificate and may receive a SmartScreen warning.

## Pipeline

`.github/workflows/native-apps.yml` builds all three editions for app/content changes
on `main` and `hiraia-unified`. The protected, while-awake Mac runner restores private
inputs, runs the five-draw model gate, builds and release-signs both APKs, and exports
Windows renderer assets. GitHub's Windows runner builds and relocates the ZIP and runs
the packaged application tests. `all-platforms.json` is emitted only when all editions
share a commit/version and all required evidence is green. Private signing inputs never
leave the Mac. Same-commit branch pushes collapse into one build. Nothing publishes
automatically; the existing immutable R2 publisher verifies an authorized upload by
reading it back and checking its public URL.
